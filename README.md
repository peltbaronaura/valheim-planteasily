## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Mass Plant** | Plant entire rows or grids in one cultivator sweep |
| **Pattern Modes** | Switch between row, grid and radial planting patterns |
| **Preview Ghost** | See placement preview before committing to plant |
| **Seed Counter** | Inventory seed count shown while planting to avoid running dry |
